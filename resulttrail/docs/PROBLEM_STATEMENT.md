# Track 5 problem statement — ResultTrail

**Brief:** Track 5, chiefly 5C evidence hygiene and 5E feedback loop, with an offline capture component from 5A.

**User and pain:** A trained independent observer recording an illustrative polling-unit result copy may lose connectivity before a report reaches a shared service. Later, the observer and reviewer need to know which version was received, whether it was checked, and what correction was requested. A screenshot or chat message alone does not provide a consistent version history or verifiable server receipt.

**Working prototype:** ResultTrail guides the reporter through structured figures and evidence checks, encrypts unsent work on the device, syncs when online, verifies a signed receipt, and displays review feedback. Reviewers compare figures and an optional source image, record a human decision, and can export only an approved latest version. Precise locations and images are accessible only within the assigned project workspace.

**Boundary:** This is an independent research demonstration using fictional records. It cannot prove the paper copy is authentic, detect fraud, declare a result, or operate as an official election system. No live electoral system is used.
